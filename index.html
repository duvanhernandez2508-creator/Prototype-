Etapa 4

Alcance y funcionamiento

Arquitectura práctica

  1. Aplicación web instalable: funciona en celular o computador.
  2. Almacenamiento local: permite capturar registros con conectividad limitada.
  3. Cola de sincronización: conserva cambios pendientes y los envía al recuperar internet.
  4. Firebase opcional: autentica usuarios y centraliza datos cuando se configure.

Sensores: simulación vs. realidad

Este prototipo no afirma recibir lecturas físicas. Las tarjetas etiquetadas DEMO / SIMULADAS fueron creadas solo para evaluar el flujo.

Para operar con sensores reales, se requiere un sensor de humedad calibrado, microcontrolador/gateway, conectividad y una API segura. Cada lectura debe incluir finca, sensor, unidad, fecha y calidad de señal.

Uso ético y sostenible

Solicitar consentimiento para datos productivos, limitar el acceso por rol, no reemplazar el criterio técnico y validar recomendaciones antes de aplicarlas. Priorizar registros útiles aun con baja conectividad.
